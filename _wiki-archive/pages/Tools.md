You can upgrade certain tools at the [Blacksmith](Blacksmith.md) shop. Others are found or given to you by characters.

| Item                                                             | Obtained                        | Description                                                                                                                                                              |
|------------------------------------------------------------------|---------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ![ ](../images/Rusty_Watering_Can.png) *Rusty Watering Can*      |                                 | You can use this watering can on your crops, but it doesn't hold much water. [Natalia](Natalia_Kuznetsova.md) can upgrade it for you in her [blacksmith](Blacksmith.md). |
| ![Rusty Wood Axe](../images/Rusty_Wood_Axe.png) *Rusty Wood Axe* |                                 | This axe can cut down logs and some trees, but it requires a lot of energy. [Natalia](Natalia_Kuznetsova.md) can upgrade the axe in her [blacksmith](Blacksmith.md).     |
| ![Rusty Pickaxe](../images/Rusty_Pickaxe.png) *Rusty Pickaxe*    |                                 | This pickaxe can break up small rocks and boulders, but it requires a lot of energy. [Natalia](Natalia_Kuznetsova.md) can upgrade it in her [blacksmith](Blacksmith.md). |
| ![Fishing Rod](../images/Fishing_Rod.png) *Fishing Rod*          | Gift from Bruno.                | [Bruno](Bruno_Soft.md) gifted you this fishing rod, which you can use to catch fish as long as you have enough bait.                                                     |
